# open-pdk-hub
"A unified, node-agnostic platform for ASIC Physical Design. Run complete RTL-to-GDSII flows on 2nm–130nm nodes (ASAP7, Sky130, GF180) using OpenROAD &amp; SiliconCompiler. Includes predictive (research) and manufacturable (tape-out) PDKs with standardized scripts and benchmark designs."
